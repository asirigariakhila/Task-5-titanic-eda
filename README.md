# Task 5 – Exploratory Data Analysis

## Objective
Extract meaningful insights from the Titanic dataset using visual and statistical exploration.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Dataset structure and data types
- Descriptive statistics
- Missing value analysis
- Value counts
- Histograms
- Boxplots
- Scatterplots
- Pairplot
- Correlation heatmap
- Survival analysis
- Identification of patterns, trends and anomalies

## Key Findings
- Female passengers had higher survival outcomes than male passengers.
- First-class passengers generally had better survival outcomes.
- Fare contained several high-value outliers.
- Cabin had substantial missing values.
- Passenger class and fare showed a noticeable relationship.
